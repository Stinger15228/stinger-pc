# STINGER PC — Официальный сайт-витрина кастомных игровых ПК

Сайт-витрина для продажи игровых компьютеров в Великом Новгороде с перенаправлением в личные сообщения на Авито.

## 🚀 Как запустить локально для просмотра
Если вы хотите посмотреть сайт на своем компьютере:
1. Запустите файл `server.js` (через команду `node server.js`).
2. Откройте в браузере: `http://localhost:3000`

---

## 🛠 Как менять цены, сборки и контакты

Все настройки и данные сайта вынесены в один файл — **`config.js`**. 
Вам **не нужно** редактировать HTML или верстку!

### 1. Как изменить контакты (Авито, Telegram, VK):
В начале файла `config.js` найдите блок `contacts`:
```javascript
contacts: {
  avitoUrl: "https://www.avito.ru/...", // Ваша ссылка на профиль или чат
  telegramUrl: "https://t.me/...",      // Ваш Telegram
  vkUrl: "https://vk.com/...",          // Ваша группа VK
}
```

### 2. Как изменить цену сборки:
В массиве `products` найдите нужный компьютер и измените число в поле `price`:
```javascript
{
  id: "pc-4",
  name: "STINGER Power",
  price: 71725, // Новая цена
  ...
}
```

### 3. Как добавить или убрать ПК:
Просто добавьте новый блок в массив `products` по аналогии с существующими или измените статус `inStock: false`.

## 📦 Размещение на GitHub Pages (Бесплатный хостинг)
1. Создайте публичный репозиторий на GitHub (например, `stinger-pc`).
2. Загрузите файлы сайта в репозиторий.
3. В настройках репозитория перейдите в **Settings → Pages** и выберите ветку `main` (папка `/root`).
4. Через 1 минуту ваш сайт станет доступен всему миру по адресу: `https://<ваш-логин>.github.io/stinger-pc/`!
